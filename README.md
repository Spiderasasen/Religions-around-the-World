# Religions Around the World
This project started as a way for me to practice React, but it quickly grew into something more meaningful. I wanted to explore different religions, their branches, and where they are most commonly practiced. Building this app let me learn both the tech stack and the subject matter at the same time.

# React
This is one of my first full React projects. After getting a taste of React during J‑Term, I wanted to dive deeper into the language and understand how to build a real, dynamic frontend. This project gave me the perfect excuse to experiment with components, routing, and fetching data from an API.

# Backend
Even though the original plan was “just frontend,” I ended up expanding the project into a full-stack build.
I set up:
- a MySQL database
- a Python FastAPI backend
- routes for religions, branches, regions, and texts
- SQL queries to pull everything together
It was a fun challenge and a great way to strengthen my backend skills while keeping the project practical.

# Why There’s No Public Page
Right now, the site runs entirely on my local machine. The API and SQL database need to be online 24/7 for a public version, and that’s not realistic at the moment. Once I have a dedicated server setup, I might host it properly.
If you know me in person, I’m always happy to show you the live version — it’s just a bit too heavy to keep running publicly for now.
